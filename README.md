### Расшифровка статусов

- `NEW` — задача создана, работу ещё не начинали.
- `IN_PROGRESS` — задача в работе.
- `REVIEW` — работа по задаче сделана и отправлена на проверку/приёмку.
- `DONE` — задача принята/завершена.
- `BLOCKED` — выполнение невозможно/отменено/заморожено (по причине).

### Ограничения (правила)

- В статусе `BLOCKED` нельзя создавать записи времени (`TimeRecord`).
- Создавать запись времени (`TimeRecord`) можно только для задач в статусе `DONE`.
