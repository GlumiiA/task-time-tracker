# Таблицы прецедентов использования

Ниже собраны прецеденты использования по диаграмме [docs/diagramms/usecase.drawio.svg](docs/diagramms/usecase.drawio.svg).

## UC-01: Просмотреть список своих задач

| Поле | Значение |
|---|---|
| Название | Просмотреть список своих задач |
| ID | 1 |
| Краткое описание | Авторизованный пользователь видит список задач, доступных ему в системе. |
| Главные акторы | Работник |
| Второстепенные акторы | Администратор |
| Предусловия | Пользователь авторизован и находится на странице задач. |
| Основной поток | 1. Пользователь открывает страницу задач.<br>2. Система загружает доступные задачи.<br>3. Система отображает список задач. |
| Альтернативный поток | A1. Если список пуст, система отображает сообщение об отсутствии задач. |
| Постусловия | Пользователь видит актуальный список своих задач. |

## UC-02: Просмотреть детали задачи

| Поле | Значение |
|---|---|
| Название | Просмотреть детали задачи |
| ID | 2 |
| Краткое описание | Пользователь открывает полную карточку выбранной задачи. |
| Главные акторы | Авторизованный пользователь |
| Второстепенные акторы | Нет |
| Предусловия | Пользователь авторизован, задача существует. |

| Альтернативный поток | A1. Если задача не найдена, система возвращает ошибку 404. |
| Постусловия | Пользователь видит детальную информацию по задаче. |

## UC-03: Создать запись о затраченном времени на задачу

| Поле | Значение |
|---|---|
| Название | Создать запись о затраченном времени на задачу |
| ID | 3 |
| Краткое описание | Работник фиксирует затраченное время по выполненной задаче. |
| Главные акторы | Работник |
| Второстепенные акторы | Администратор |
| Предусловия | Пользователь авторизован, задача существует и находится в статусе `DONE`. |
| Основной поток | 1. Пользователь заполняет форму записи времени.<br>2. Система проверяет данные и права доступа.<br>3. Система сохраняет запись времени.<br>4. Система возвращает созданную запись. |
| Альтернативный поток | A1. Если задача не `DONE`, система возвращает конфликт `409 Conflict`.<br>A2. Если пользователь пытается создать запись за другого сотрудника, система возвращает `403 Forbidden`. |
| Постусловия | Запись времени сохранена в системе. |

## UC-04: Изменить статус задачи

| Поле | Значение |
|---|---|
| Название | Изменить статус задачи |
| ID | 4 |

| Второстепенные акторы | Администратор |
| Предусловия | Пользователь авторизован, задача существует, новый статус передан в запросе. |
