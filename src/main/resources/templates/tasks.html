Создание задач

Создавать задачи и назначать исполнителей может только администратор.

Вы можете:

  • просматривать только свои задачи;
  • менять статус своих задач;
  • создавать записи рабочего времени.

Записать время

Запись времени создается только для задачи со статусом DONE.

Задачи

Администратор видит все задачи и может фильтровать их по исполнителю и статусу.
